# 3D Graphics Engine for Simulation Visualization
## Main Goal
The goal of this project is to build a 3D graphics engine that is tailored to visualize 3D simulations.
This will be achieved with a list of tools, design to speed up the workflow of simulation visualization.
Examples:
- Prebuilt simple objects
- Runtime mesh generation
- Built in marching algorithms to visualize point girds as meshes
- Tools to visualize vector fields, volumetric data, such as density
- Ability to handle animated objects and tools to easily analyise the simulation
